# 实验室数据归档 SOP｜试用稿 v0.1

**目标**：把值得长期保留的一份研究结果，从运行工作区整理为同事能找到、读懂、核验和引用的版本。适用于 HelixWeave 产物及 R 等外部分析。筹划、实际归档、清理是三个不同的动作。此文不表示已有通用归档命令；未具备目标端核验和登记能力时，停在清单或“已复制、待登记”，不要清理原件。

## 怎样分类

| 日常查找入口 | 登记依据与粒度 |
| --- | --- |
| 课题 | 选择归属项目的稳定 ID 和可读名称；结果不因课题改名而搬盘。无法确认归属，先待核对。 |
| 细胞或材料 | 用样本的确切修订关联细胞类型、细胞系等已知属性。三者分别填写，不从文件名猜。组织材料、混合样本或尚未注释的数据，可以注明组织、混合、未知或不适用，不强填细胞类型。 |
| 实验 | 记录实验方法和具体实验记录/批次的已知身份；方法相同的两次实验仍可区分。下游计算记录分析方法及父数据，不虚构一次湿实验。 |
| 科学结果 | 一份可独立解释和引用的结果为一个逻辑单位。记录结果类型、版本、必要成员和来源。样本级、整批级、跨组比较分别记录作用范围，不能把整批结果算成某一个细胞样本的结果。 |

长期盘按项目和结果版本各保存一份受管内容；按细胞、实验或其他条件生成目录视图或索引。一份跨组比较可以从两个组找到，但仍是同一份结果。临时盘仍按 run 分开。原始数据与已受管参考应有独立保管位置，不能把工作区当唯一原件。

## 谁做什么，做到哪一步

1. **准备证据（研究者）**：提供项目、实验记录、样本/输入修订、结果清单或外部分析说明；列出已确认的信息和缺口。优先使用产物清单与实验记录，文件名只能帮助寻找证据。对只由外部团队保管的文件注明“仅引用”。
2. **筛选（研究者，可由 AI 起草）**：优先保留支撑研究结论的主数据、读取它必需的索引、解释它必需的 QC、参数和来源。昂贵或不可再生的中间结果单列，由负责人决定。缓存、重试残留和短期检查点默认不进入长期盘；“不归档”不等于“可以删除”。QC 未通过但有审计或排错价值的结果可按异常状态保留，不能标成合格数据。
3. **确认计划（课题负责人或受委托者）**：逐项标记“拟保留 / 仅引用 / 暂存 / 不纳入 / 待核对”，附理由，核对目标项目、版本、文件角色、上游来源和必要成员。无法确定文件归属或缺少必需索引，暂停受影响的那一份；其他独立结果可以继续。人可以调整 AI 建议；留下确认人和清单版本。
4. **交接与登记（授权运维）**：按确认清单复制到长期盘的暂存位置；从目标端逐项核对大小和内容摘要，对照确认时的源文件版本或已有登记摘要。成员齐全、来源未变且核验通过，才提交可读位置和清单并回读一次，核对原结果或固定版本入口仍指向同一内容。运行成功、文件已复制、已归档是不同的状态。目标盘离线、摘要不符、登记失败时保留原件并记录阶段；同一计划重试不能多出一份有效归档。不覆盖历史版本。
5. **清理（独立运维权限）**：保留期限届满后再按项目策略处理工作副本，先确认受管的长期副本可读、没有恢复执行或下游依赖需要原路径。唯一副本、仅引用的外部原件均不在本流程的自动清理范围。归档清单或 AI 回复均不能充当删除授权。

## 两次桌面演练（均为合成情境，没有搬动文件）

**Hi-TrAC 预处理。** 课题 P、运行 R 有已发布的样本 S 配对产物 all/noBg 以及整批 summary；另见排序缓存。项目已确认本次需要复用两份配对产物。将二者标为拟保留，连回 S 的样本修订及准确产物修订；summary 保留一次并标为整批，不复制为 S 的专属 QC。引用运行参数和参考修订；缓存标为不纳入。若实验记录只有细胞系而没有细胞类型，类型留未知。没有目标端摘要和回执，结论是“待归档”。

**R 下游分析。** 课题 P 有一张 A/B 两组比较表和生成脚本。表与可复现所需脚本/参数拟保留；从同一份结果关联两个组，记录两份输入各自的版本与比较角色，不建立虚构 run。若 B 的文件只写着 latest，先保留唯一原件，将精确来源标为待核对，不声称可完全复现。补齐版本后归档一次，按 A、B 或实验分类均能查到；不因 A 后来换版而改写旧比较的来源。
