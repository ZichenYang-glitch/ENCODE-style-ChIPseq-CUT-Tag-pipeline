# 实验室长期数据目录：按研究结果归档
供讨论的设计草案。参照主干 `65d99776` 的[数据基础决策](data-foundation-decision.md)和[产物发布语义](artifact-publication-provenance-decision.md)。示例路径、数据关系与操作是提议，不是当前命令或迁移指令。

试用入口：[实验室数据归档 SOP 与清单模板](../../.agents/skills/helixweave-archive-plan/references/lab-archive-sop.md)；[归档规划 skill](../../.agents/skills/helixweave-archive-plan/SKILL.md)。

## 先确定归档单位
运行是一次计算；长期保存的是可以交给同事、引用或用于下一步分析的一份研究结果。一轮运行可能交付零个、一个或多个结果；一份下游结果也可能依赖多轮运行。没有 HelixWeave run 的结果同样可以登记。实验、样本、结果、运行各有自己的身份，不能用一个 run 或一个目录名代替。实验可以先登记，暂时没有结果。

一份结果版本可以含主数据、必需索引、必要 QC 和说明，清单按角色列出文件、大小和内容摘要。只有预期成员齐全、核验通过才算这一版已归档。未验证的图、失败运行的日志也可以按实际目的保留，明确标明状态；不要把保留等同于质量合格。为恢复执行保留的检查点另设期限。

## 物理目录简单，科学分类允许多维
建议按受管项目、数据大类、稳定对象、不可变版本组织长期盘；例如：

    scratch/runs/<run-id>/...
    storage/projects/<project-id>/inputs/<input-id>/<version>/...
    storage/projects/<project-id>/results/<result-id>/<version>/...
    storage/projects/<project-id>/results/<result-id>/<version>/manifest.json

示意中的版本路径是定位手段，不是身份权威。允许文件名保留可读的领域含义；项目显示名、组织或细胞类型改名不搬目录。每个项目可从目录库按需导出可读索引（显示名、类型、样本或批次、版本、相对路径）；它是导航，不是第二份可编辑账簿。既有托管方保存的外部文件可只登记引用，不强制复制，也不取得清理权。

- 项目是归属边界；实验方法、物种、条件、样本、结果类型是查询维度。稳定术语可配显示名和别名，缺证据记为未知。操作员或 AI 不得凭文件名认定样本归属。
- 样本关联应记录角色和依据。多样本比较只登记一次，可从各相关样本查到；仅已知某次运行使用一批样本，不表示每个产物都能归到其中某一个。
- 来源独立于分类。平台产物保留精确的运行/产物修订；外部文件说明实际来源；下游结果引用父结果的确切版本而非“最新”。审批前明确如何将既有 run 产物引用与注册结果关联，不伪造 run，不改写旧修订。

## 两条不同的轴
内容或科学解释的修订，以及物理副本的位置和可用性，要能分别查询。移盘并核实相同字节，不应被理解为做了一次新分析；新分析也不应靠覆盖旧目录发布。现行外部登记草案把路径纳入修订摘要，不能原地改路径。可保留登记时的坐标，增加相同内容的已核验副本记录；确定兼容与恢复方案后再改 schema。其他位置不可凭同名文件自动替代。

运算完成后由 adapter 列出候选文件及角色，项目策略或有权限的人选择保留哪些。预览预期文件和位置 → 复制至目标暂存区 → 从目标核验清单 → 提交可读取的位置 → 按独立保留策略清理 scratch。目标断线或内容不符时不标记成功，也不重跑科学计算；同一计划重试只产生一次有效归档。输入原件不因运行目录清理而被删除。

## 是否需要写 CLI
不另造传输程序。先定义目录操作和一份实际可读的归档清单，拿两个样例验证分类。第一版可在现有 CLI 下提供两个薄入口：预览保留清单；接收已经复制到批准存储池的文件，核验并登记。它们调用同一目录服务。rsync 或受管任务都可以负责复制。成员只读、运维授权执行，网页 Peri 不提供搬盘或删除工具。高频后再决定是否把复制编排为一条便捷命令。

## 首次验收
1. 一次合成 Hi-TrAC 运行：依据产物角色选出要保留的配对结果、必要 QC 和参数，scratch 缓存不进长期盘。清理 scratch 后，仍能按项目找到结果、读到同一版本并追到运行。
2. 一份 R 生成的两组比较表：登记为一份外部或下游结果，不创建假 run；即使父数据更新，仍能查出所用旧版本。缺少父版本依据时如实记录。
3. 给样本改分类，不移动字节；只换存储盘，不改变科学来源；文件被同名覆盖，不当作旧版；目标不可用时仍能区分“分析已完成”和“尚未归档”。

需要实验室实际决定的第一项：各流程中哪些昂贵或不可再生的数据必须留，哪些只需留到复核结束，以及谁能例外保留。先用上述两份清单试用，再定默认策略。
