## Deferred authorization gates

The candidate does not yet claim real-host deployment acceptance or a new
Protected Gate. After all ordinary evidence is green, one explicit supported-
host window may prove the minimum platform/ENCODE transition and Bulk
admission/service identity. Only then may one exact-final-functional-HEAD

and offline contracts. It does not prove biological validity, public-data
reproducibility, production-scale throughput, multi-tenancy, or high
availability.

build, checksum, GitHub Release upload/download verification, and publication
